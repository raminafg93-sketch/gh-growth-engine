# Website Inventory

## Prüfen

- URL
- Seitentyp
- Statuscode
- Canonical
- Title
- Meta Description
- H1
- Wortzahl
- interne Links
- primärer CTA
- Trust-Elemente
- Suchintention
- Überschneidungen
- widersprüchliche Aussagen

## Ergebnis

Jede URL erhält:

- KEEP
- IMPROVE
- MERGE
- REDIRECT
- NEW
- REVIEW

## Regeln

- Keine URL löschen.
- Keine neue URL empfehlen, bevor Überschneidungen geprüft sind.
- WhatsApp- und Telefon-Conversion getrennt bewerten.
- Ergebnis als CSV und Markdown-Bericht ausgeben.
